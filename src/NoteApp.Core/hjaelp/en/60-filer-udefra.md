# Audio files from outside

*A voice memo from the phone, a dictaphone, a file a colleague sent*

Meetings are not always held at the PC. An audio file can be imported and
treated like any other recording.

## Two ways in

- **The button** next to «New folder» on Recordings.
- **Drag the file into the list** from Explorer. Drop it on a folder and it
  lands in that folder.

`.m4a`, `.mp3`, `.wav`, `.aac`, `.mp4`, `.wma` and `.flac` can be read.

**The source file is never touched.** It is copied — the original stays where
it was. It usually sits in a synchronised folder, and moving it would delete
it from the phone.

The recording is dated by the **file's own date**, not by when it was
imported. A memo from last Tuesday sorts as last Tuesday.

## There is only one track

A recording made here has two sides: FROM HERE and FROM THERE. A file from
outside has one. Everything appears under the same speaker, however many
people took part, and it cannot be separated afterwards.

It is stated in three places, so it is not something to discover: on the
recording in the tree, at the top of the transcript, and as its own icon in
the list.

## Watched folders

Point the app at a folder under **Settings → Files**. If an audio file turns
up, it is offered at the top of Recordings.

By default **nothing** is watched. In return the app finds the cloud services
on the machine itself and offers one folder in each:
`<cloud service>\HeyPia`. If it does not exist, there is a button that
creates it.

The app was called NoteApp until 28 August 2026. If you already have a
`<cloud service>\NoteApp` folder, it is still found. It is yours, and the app
does not rename it just because it changed its own name.

Not the whole cloud service — then every audio file anywhere in the cloud
would have to be dealt with, podcasts and ringtones included.

Each folder can be set to **import automatically**. That is off by default: a
folder shared with others can receive an audio file that is not a meeting.

## How it looks

- Every minute, for as long as the app is open, and straight away when it
  starts.
- A file is **never** read — only its name, size and date. Files in iCloud and
  OneDrive are often only in the cloud, and reading them would pull the whole
  folder down.
- A file must have been still for twenty seconds. Otherwise it can be
  imported while it is still being copied.
- Each file is offered once. Say no and it does not come back — and the file
  stays in the folder.

If you regret a no, press **Forget what has been seen** under Settings. Then
everything is offered again.
